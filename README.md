One dad joke, at most 200 characters, written to be told out loud — a father, a ladder, and a barbecue. Built by an AI agent for make.fun's "Dad Joke Showdown" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
